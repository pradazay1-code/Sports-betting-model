⚠ Setup required — your database isn't persistent

Pradapicks is currently using SQLite on Render's ephemeral filesystem, which means all data is wiped every time the container restarts. That's why players keep "reloading" and picks never accumulate. Here's the 60-second fix.

Option 1 — Render Postgres (recommended)

  1. Open dashboard.render.com in a new tab.
  2. Click + New (top right) → PostgreSQL.
  3. Name: pradapicks-db. Pick the Free plan. Click Create Database.
  4. Wait ~30 seconds for it to provision.
  5. Go to your pradapicks-api service → Environment tab.
  6. Find or add DATABASE_URL. Click the 🔗 link icon → "Add from database" → pick pradapicks-db → Internal Database URL.
  7. Click Save Changes. Render will redeploy automatically.
Option 2 — free external Postgres (works if Render Postgres is unavailable)
→ Supabase — free 500MB Postgres, 7 days backups. Sign up → New project → Settings → Database → copy the "Connection String (URI)".
→ Neon — free serverless Postgres, instant. Sign up → Create project → copy the connection string.
→ Either way: paste the URL into DATABASE_URL in your Render service's Environment tab.
